四、上傳方法
============================================================
1. 解壓縮 ZIP。
2. 將「data」「scripts」「.github」「UPDATE_NOTES.txt」直接拖到 GitHub repo 根目錄。
3. Commit changes。
4. GitHub Actions 會自動執行「補齊 2026-09-17 韓服外觀圖片」。
5. Action 完成後會再自動 commit：index.html + 7 張本地 WebP 圖片。
6. Vercel 連接 main 分支時，兩次 commit 都會自動部署；最後一次完成後即為完整版本。

若 GitHub Actions 沒有自動啟動：
Actions → 補齊 2026-09-17 韓服外觀圖片 → Run workflow。
