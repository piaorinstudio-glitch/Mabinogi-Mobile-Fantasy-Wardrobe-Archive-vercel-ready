【部署與 HTML】
網站 GitHub Pages 不是直接發布 repo 根目錄，而是先執行 scripts/build_action_site.py 生成 site-dist。
部署工作流程將在 site-dist/index.html 中，將新增的 data/tw-update-20261125.js
置於既有 data/tw-update-20261014.js 之後、assets/js/app.js 之前，並加上版本參數。
發布前會驗證上述 8 張已在 repo 的外觀圖檔存在、七筆資料 ID 都存在；未通過則不發布。
因為 HTML 是 GitHub Pages 建置生成並注入，repo 根目錄的 index.html 不必替換；
實際對外發布的 site-dist/index.html 會載入新版資料。
請將 ZIP 解壓後直接放到 GitHub main 分支根目錄，保留 .github/workflows/ 和 data/ 路徑。
不要把整個 ZIP 本身當成網頁檔上傳。
