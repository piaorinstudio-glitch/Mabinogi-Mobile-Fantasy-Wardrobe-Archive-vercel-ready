# 專案結構檢查報告｜2026-09-07

目前已整理成適合 **GitHub 版本管理 + Vercel 靜態部署** 的結構。主頁不再把 CSS、資料與全部 JavaScript 塞在單一 `index.html`，日後大部分更新只需要修改 `data/`。

## 已檢查

- 88 筆外觀卡片資料。
- 74 個寵物變體。
- 15 個寵物技能系族。
- 1 個共用小工具（Mobilay）。

- 日期格式與 `year` 欄位一致。
- 寵物變體皆能對到固定同行能力與技能家族。
- 本地 HTML / CSS / JS / 圖片路徑檢查通過。
- JavaScript 單檔語法與瀏覽器載入順序的全檔語法檢查通過。
- 深淵／團隊副本不顯示「台服當期／台服已推出」標籤的程式規則仍保留。
- 目前站內圖片檔共 97 個。

## 結構修正

- `index.html`：從約 142 KB 的單檔案，縮成約 9 KB 的頁面骨架。
- `assets/css/main.css`：主站樣式獨立。
- `assets/js/app.js`：UI 邏輯獨立。
- `data/catalog.js`：外觀資料獨立且重新排版，方便直接增刪。
- `data/pets.js`：寵物技能／同行能力獨立。
- `data/site-config.js`：Tips、台服狀態、小工具獨立。
- `data/ads-config.js` + `assets/js/ads.js`：AdSense 集中開關。
- `assets/css/page.css`：關於／隱私／聯絡頁共用樣式，不再各自複製 CSS。
- 過去一次性的 `apply_*.py` 修補腳本移到 `scripts/legacy/`，避免之後誤跑舊 patch 把新版 `index.html` 改壞。
- 舊 GitHub Action patch workflow 已移除；Vercel 直接使用 GitHub integration 部署，不需要這些會自動改檔案的 workflow。
- 移除未使用的重複圖片與舊圖片副本，舊報告移到 `research/reports/`。

## Google AdSense

- `ads.txt` 保留在網站根目錄。
- `google-adsense-account` meta 保留。
- 目前 `data/ads-config.js` 為 `enabled:false`，因此測試版不會載入 Google 廣告網路 script。

- `privacy.html` 已有 Cookie / AdSense 說明。
